# Monstar 1.1.0

Released 2026-11-08.

## Highlights

- Prebuilt binaries and Arch packages now cover aarch64 as well as x86_64.
- Frames reach the compositor as dma-bufs where `/dev/udmabuf` is available,
  sparing the compositor a copy per frame, and an optional Vulkan renderer is
  available with `renderer = vulkan`.
- Text is rendered in linear light and thickened like macOS Core Text by
  default.
- Ghostty-style `keybind` entries, including actions that send text or CSI
  sequences and copy or paste the clipboard.
- `config-file` includes and a `term` setting make Monstar easier to integrate
  into desktops that manage terminal configuration, such as Omarchy.
- Kitty graphics animation, relative placements, and drag-out from terminal
  programs.

## Added

- `config-file`, which loads more configuration files after the file that
  names them. A leading `?` ignores a missing file, and included files are
  re-read on reload.
- Repeatable `keybind = trigger=action` entries with the `scroll_page_lines`,
  `new_window`, `copy_to_clipboard`, `paste_from_clipboard`, `text:`, `csi:`,
  and `unbind` actions. `Ctrl+Shift+N` opens a new window in the current
  directory, with or without systemd.
- `term`, which sets the child's `TERM`, for example `term = xterm-256color`
  for hosts without Monstar's terminfo.
- `background-blur = always`, which requests compositor blur even behind an
  opaque background, for compositors that fade whole windows with their own
  opacity rules.
- `renderer = cpu|vulkan` and `presentation = auto|shm|dmabuf`. The Vulkan
  loader is only loaded when the Vulkan renderer is selected.
- `font-thicken` and `font-thicken-strength`.
- `adjust-cell-height` and Ghostty's line thickness adjustments.
- `window-width`, `window-height`, and `working-directory` settings.
- Optional desktop notifications when long-running commands finish
  (`notify-on-command-finish`), for shells that emit OSC 133 markers.
- Smooth pixel-level scrolling, including eased mouse wheel steps, controlled
  by `smooth-scrolling`.
- `cursor-color` and `cursor-text` accept `cell-foreground` and
  `cell-background`.
- `Ctrl` + right click copies a hyperlink or detected URI.
- Kitty graphics animation and relative placements, the Kitty clipboard
  protocol, and Kitty drag-out with previews.
- Monochrome bitmap fonts and color emoji presentation by default.
- A Nix flake and an installed example Fontconfig profile.
- The `-Dembed-nerd-font=false` build option, which drops the embedded Nerd
  Font symbols.

## Changed

- `TERM` is now `monstar`, backed by a terminfo entry installed with Monstar,
  instead of `xterm-ghostty`. `COLORTERM` is set to `truecolor`.
- Text is blended in linear light with corrected coverage, and
  `font-thicken` is on by default, so text looks heavier than in 1.0.1.
- Cell height now includes the font's line gap, as in Ghostty. Fonts with a
  line gap get taller rows.
- Desktop notifications from the terminal are suppressed while the window has
  keyboard focus.
- The desktop entry is named Monstar.
- Building from source requires Zig 0.17 and the Vulkan headers.

## Fixed

- Output written just before the child exits is no longer lost.
- Key repeat timing, Ctrl+Shift punctuation encoding, XKB layout handling for
  shortcuts, virtual keyboard input, and compose cancellation.
- Text input focus is released when keyboard focus or the seat goes away.
- Clipboard and drag-and-drop transfers no longer block the event loop, and
  malformed or oversized transfers are rejected.
- Oversized or overflowing Kitty graphics placements are rejected.

## Upgrade notes

- Remote hosts without Monstar's terminfo do not recognize `TERM=monstar`.
  Install it there with `infocmp -x monstar | ssh HOST tic -x -`, or set
  `term = xterm-256color`.
- Set `font-thicken = false` to return to unthickened text.
- Use `adjust-cell-height` if the new line-gap spacing makes rows taller than
  you want.
