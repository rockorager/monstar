# Monstar 1.2.0

Released 2026-11-12.

## Added

- Copying a selection now also snaps corner brackets in the `copy-highlight`
  color around it, so the copy is easy to see. They follow scrolling and
  rectangle selections and retract after a moment. Desktops that request
  reduced motion keep the plain flash, and `copy-highlight-duration = 0`
  disables both.

## Fixed

- Monstar no longer sends a color scheme report each time an application
  enables color scheme notifications (mode 2031). fish enables them at every
  prompt, so after short paged commands `?997;1n` could appear in its command
  line. Applications still receive a report when the desktop's color scheme
  changes while notifications are enabled, or when they query it with
  `CSI ? 996 n`.
- The Nix flake's package now takes its version from `build.zig.zon`, so it is
  named for the release it builds.
