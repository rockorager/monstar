# Monstar 1.4.0

Released 2026-11-24.

## Added

- Super+D closes a `--rex` window but leaves its shell running on the Rex
  server. The key is the new `rex_detach` keybinding action, so it can be
  rebound with `keybind`; in other windows Super+D goes to the application.
  Closing a `--rex` window any other way still closes its shell.
- `--rex-block ID`, with `--rex`, opens a window on a running shell of the
  server's `monstar` session, such as one left running with Super+D, instead
  of starting a new one. The window comes back with the shell's screen and
  scrollback. The ID is the block ID that
  `rex api call -s monstar session.list_blocks` reports.
