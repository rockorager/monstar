# Monstar 1.4.1

Released 2026-11-24.

## Added

- `extras/omarchy/` has a "Rex hosts" picker for the Omarchy menu. It lists
  this machine and the hosts from `rex hosts`, then "New shell" and the
  chosen host's running monstar shells, detached ones first, and opens a
  monstar window on the choice with `--rex` and `--rex-block`. It loads a
  remote host's shells over a single connection. See
  `extras/omarchy/README.md` to install it; it needs Omarchy 4, `rex`, and
  `jq`.
