# Monstar 1.1.1

Released 2026-11-10.

## Changed

- The default `presentation = auto` now sends frames to the compositor through
  wl_shm again. Monstar 1.1.0 sent them as dma-bufs through `/dev/udmabuf`,
  which showed stale or corrupted regions on some systems, including Niri with
  NVIDIA's proprietary driver. Dma-buf presentation is still available with
  `presentation = dmabuf`, which now warns whenever it falls back to wl_shm.

## Fixed

- Kitty graphics images whose placement extends past the image's edge no
  longer crash Monstar, for example when scrolling through image previews in
  Yazi.

## Upgrade notes

- If you relied on the 1.1.0 default to reduce compositor CPU usage, set
  `presentation = dmabuf`.
