# Monstar 1.3.0

Released 2026-11-24.

## Highlights

- `monstar --rex TARGET` opens a shell on a [Rex](https://www.superlogical.com/rex)
  server instead of running a local command.

## Added

- `--rex TARGET` runs each window as a new shell in the Rex server's `monstar`
  session. TARGET is `local` for this machine's server, a host with a Rex
  tailnet listener (port 7297 by default), `http://host:port`, or
  `unix:///path`. Closing the window closes the shell, and the shell exiting
  closes the window. Keys, pastes, mouse, and focus go to the shell as Rex
  events, so it encodes them for the program's own modes, and Monstar pushes
  its size and colors so the program sees them when it queries. HTTPS
  endpoints are not supported yet.
- `copy-on-select` chooses what finishing a mouse selection copies: `true`, the
  default, copies it to the primary selection as before; `clipboard` also
  copies it to the clipboard; `false` copies nothing.

## Changed

- The release tarballs are reproducible and now include `LICENSE` and
  `README.md`.
